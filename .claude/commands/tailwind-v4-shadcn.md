# Tailwind v4 + shadcn/ui

Reference for Tailwind CSS v4 with shadcn/ui and Radix UI components. Prevents known v4 migration errors that general knowledge misses.

> Source: `secondsky/claude-skills@tailwind-v4-shadcn` (3.2K installs)

## Critical: v4 is fundamentally different from v3

| Area | v3 | v4 |
|---|---|---|
| Config file | `tailwind.config.js` | CSS-first via `@theme` directive |
| Plugin system | `plugins: [...]` in config | `@plugin` in CSS |
| PostCSS | `tailwindcss` PostCSS plugin | `@tailwindcss/vite` (Vite projects) |
| Color system | `theme.extend.colors` in JS | CSS variables in `:root` |
| Animations | `tailwindcss-animate` | `tw-animate-css` (v4 compatible) |

## Four-Step Architecture

### 1. Define CSS variables at root level with `hsl()` wrapper

```css
/* src/index.css */
@import "tailwindcss";

:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 221.2 83.2% 53.3%;
  --primary-foreground: 210 40% 98%;
  --border: 214.3 31.8% 91.4%;
  /* ... all design tokens */
}

.dark {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  /* ... dark mode values */
}
```

### 2. Map to Tailwind utilities via `@theme inline`

```css
@theme inline {
  --color-background: hsl(var(--background));
  --color-foreground: hsl(var(--foreground));
  --color-primary: hsl(var(--primary));
  --color-primary-foreground: hsl(var(--primary-foreground));
  --color-border: hsl(var(--border));
}
```

### 3. Configure Vite plugin (NOT PostCSS)

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'  // ← v4 way

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),  // ← NOT postcss.config.js
  ],
  resolve: {
    alias: { '@': '/src' },
  },
})
```

### 4. Initialize shadcn/ui

```bash
npx shadcn@latest init
```

Select: TypeScript, Vite, CSS variables for colors.

## Common v4 Migration Errors

### Error: `tailwindcss-animate` not found / not working
**Fix:** Replace with `tw-animate-css`
```bash
npm uninstall tailwindcss-animate
npm install tw-animate-css
```
```css
/* index.css */
@import "tw-animate-css";
```

### Error: Duplicate `@layer base` blocks
**Fix:** Merge into a single `@layer base` block. Multiple declarations conflict in v4.

### Error: Wrong `@plugin` syntax
```css
/* ❌ v3 style (doesn't work in v4) */
/* tailwind.config.js: plugins: [require("@tailwindcss/forms")] */

/* ✅ v4 style */
@plugin "@tailwindcss/forms";
```

### Error: `bg-[#hex]` or arbitrary color values not working as expected
**Fix:** Define a CSS variable instead:
```css
/* Don't: bg-[#0a0a0a] */
/* Do: define --color-custom: #0a0a0a in @theme, use bg-custom */
```

### Error: Dark mode not applying
**Fix:** Verify `.dark` class is on `<html>` and `@theme inline` has dark mode variables mapped.

## shadcn/ui with v4

```ts
// components.json — generated by shadcn init
{
  "style": "default",
  "tailwind": {
    "config": "",  // empty — v4 uses CSS config
    "css": "src/index.css",
    "baseColor": "slate",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"
  }
}
```

```ts
// lib/utils.ts — required by shadcn components
import { type ClassValue, clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

## Dark Mode Toggle (Radix + v4)

```tsx
import { useEffect, useState } from 'react'

function ThemeToggle() {
  const [dark, setDark] = useState(
    () => document.documentElement.classList.contains('dark')
  )

  useEffect(() => {
    document.documentElement.classList.toggle('dark', dark)
    localStorage.setItem('theme', dark ? 'dark' : 'light')
  }, [dark])

  return <button onClick={() => setDark(d => !d)}>Toggle</button>
}
```
