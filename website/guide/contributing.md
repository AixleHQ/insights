# Contributing to Aixle Insights

Aixle Insights is open source under the [Apache 2.0 License](https://github.com/AixleHQ/insights/blob/main/LICENSE).

> **Full details:** [CONTRIBUTING.md →](https://github.com/AixleHQ/insights/blob/main/CONTRIBUTING.md)

## Quick checklist

1. Fork the repo and create a branch from `main`
2. Follow the [Quickstart guide →](/quickstart) to get the stack running
3. Make your changes, run `make lint` and `make test`
4. Sign off every commit: `git commit -s -m "type(scope): description"`
5. Open a PR — the DCO bot checks sign-offs automatically
